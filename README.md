# 声波冲浪

一个零依赖的像素风浏览器小游戏。直接用浏览器打开 `index.html`，或通过本地 HTTP 服务访问。

## 操作方式

- 点击“开始冲浪”并允许麦克风权限，对着麦克风吹气或发声，声音越大，冲浪板升得越高。
- 也可以按住空格键，或在游戏画面上按住鼠标/触屏，产生助推。
- 每隔一段时间会进入安静潜行区；保持安静，避免警报蓄满。
- 在 60 秒内越过尽可能多的浪头。碰到浪头或潜行警报响起即结束。

麦克风需要浏览器支持，并在安全来源（例如 `localhost` 或 HTTPS）中运行。声音只在本机通过 Web Audio API 分析，不录音、不上传。拒绝麦克风权限后仍可使用键盘或触屏操作。
